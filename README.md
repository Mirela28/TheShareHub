# The Share Hub

## Introduction

The Share Hub is a peer-to-peer rental platform that allows the users to request any item offered by other people, whether it is a bike for a weekend trip or a professional camera for a holiday. On the website, you can post your own available items, or view others based on categories and request them by selecting your desired rental period. After that, the owner will either accept or decline it. TheShareHub is a sustainable platform providing temporary rentals instead of buying things you do not need for a long time and encouraging sharing economy.

## Features
- Accounts system, JWT-based authentication
- Item creation and listing
- All items viewing based on filters (search query, category, price)
- Rent request on time range selection and stripe payment
- Management of sent and received requests

## Tools & Technologies
